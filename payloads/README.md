# Payloads (фаза 2)

Сюда кладётся payload (`.bin`) для отправки на консоль через fusée gelée —
например, `hekate_ctcaer_*.bin`. Файл выбирается во вкладке RCM; бинарники
в git не хранятся (`.gitignore`).

Принципы:
- Только RAM-исполнение, без записи на eMMC; перед отправкой — подтверждение.
- Требуется незалоченная erista (patched/mariko не примут эксплойт).
- Стадия-1 (intermezzo) встроена в программу: собственная реализация,
  собирается и верифицируется дизассемблером — `uv run python tools/build_intermezzo.py`.

Ограничение: hekate/nyx показывает данные (eMMC health, батарея, фьюзы)
на экране консоли и по USB не отдаёт; PC-парсинг — фаза 2.5 (кастомный payload).
