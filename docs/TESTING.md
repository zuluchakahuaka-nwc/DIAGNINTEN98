# Политика тестирования DIAGNINTEN98

Обязательные правила для контрибьюторов (и агентов): изменения сопровождаются
тестами, скриншоты UI сверяются с золотым эталоном, включая проверку зрением (VLM).

## Уровни тестов

| Уровень | Где | Инструменты |
|---|---|---|
| Компонентные (логика без Qt) | `tests/unit/` | pytest |
| GUI (виджеты) | `tests/gui/` | pytest + pytest-qt (offscreen) |
| E2E (скриншоты всех вкладок × все языки) | `tests/e2e/` | pytest-qt + `diagninten98.capture` |

## Команды

```
uv run pytest                  # всё (12+ тестов, включая e2e)
uv run pytest -m "not e2e"     # без скриншотов
uv run python tools/golden.py  # перегенерация золотых скриншотов
```

## Скриншоты и золотой эталон

- E2E-тесты всегда снимают актуальные скриншоты всех вкладок на всех языках
  интерфейса (RU/EN/ZH) в `artifacts/screenshots/` — каталог не коммитится.
- Золотой эталон — `tests/golden/` (коммитится). Имена файлов:
  `tab_<индекс>_<ключ вкладки>_<язык>.png`, только ASCII.
- Правило обновления золота: только осознанно, после ожидаемых изменений GUI,
  отдельным коммитом `golden: update after <что изменили>`. При неожиданном
  расхождении чинится код, золото не трогается.

## Проверка зрением (VLM / MCP)

После **любых** изменений GUI (вкладки, кнопки, тексты, layout):

1. `uv run pytest tests/e2e` — обновить актуальные скриншоты.
2. Побайтовый предфильтр: сравнить золотые и актуальные PNG (`Get-FileHash`).
3. VLM-сверка выборочно (минимум одна вкладка на язык + контроль читаемости):
   - `ui_diff_check(expected, actual)` — «перечисли все расхождения; если нет — IDENTICAL»;
   - `analyze_image(скриншот)` — «перечисли видимые вкладки/кнопки; есть ли tofu (□)?».
4. Вердикт проверки фиксируется в сообщении коммита.
5. При HTTP 429 от vision-сервиса — запросы строго последовательно, без
   параллельного залпа.

## Особенности рендера offscreen

Offscreen-Qt (FreeType) не использует подстановку шрифтов Windows:

- `QT_QPA_PLATFORM=offscreen` + `QT_QPA_FONTDIR=C:\Windows\Fonts` — даёт
  кириллицу/латиницу (задаётся в `tests/conftest.py` до импорта Qt);
- CJK-шрифты лежат в `.ttc`-коллекциях и требуют явной регистрации:
  `diagninten98.fonts.register_offscreen_fonts()` — вызывается из session-fixture
  в `tests/conftest.py` и в `tools/golden.py` после создания `QApplication`.
  Без этого китайский интерфейс рендерится квадратами (tofu).

## Гейты перед коммитом

- [ ] `uv run pytest` зелёный (включая e2e)
- [ ] при изменениях GUI — скриншоты сверены (hash + зрение)
- [ ] золото обновлено осознанно и отдельным коммитом (если требовалось)
