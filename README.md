# DIAGNINTEN98

**EN:** Read-only hardware diagnostics for the Nintendo Switch (2017, HAC-001 "erista"/"mariko") on Windows.
**RU:** Диагностическая программа для Nintendo Switch 1 (HAC-001) под Windows. Только чтение состояния и анализ поломок — **ничего не записывается на консоль**.

## Возможности (по фазам)

| Фаза | Что входит | Статус |
|---|---|---|
| 0 | Каркас проекта, git, зависимости | ✅ |
| 1 | USB-монитор (cfgmgr32: детект APX/RCM `0955:7321`, MTP `057E:2010` — без драйвера), чтение Device ID по RCM (16 байт, EP 0x81), ревизия по серийнику, мастер поломок, отчёт TXT/JSON | ✅ |
| 2 | Отправка payload через fusée gelée (RAM-only, свой intermezzo), статус драйвера APX + Zadig-гайд. Данные hekate — на экране консоли; PC-парсинг требует кастомного payload (см. PLAN) | 🔶 частично |
| 3 | База кодов ошибок (2162-xxxx и т.п.), история по серийникам | ⬜ |

## Профиль консоли (А/Б)

На вкладке RCM: **вариант А** (обычная) / **Б** (с глитч-модчипом: PicoFly, HWFly, др.) + **модель**
(V1 / V2 / Lite / OLED). Профиль меняет диагностику:
- для Б группа «Модчип» — первый подозреваемый в мастере поломок, модчиповые причины — в топ;
- трактовка RCM в мониторе предупреждает о принудительном RCM (глитч-цикл);
- модель даёт поколение (Lite/V2/OLED = mariko) и контекст (на Lite стики несъёмные — ремонт = пайка);
- профиль сохраняется и попадает в отчёт.

## Драйвер APX (RCM)

Для работы с консолью в режиме RCM устройству `APX` (VID `0955`, PID `7321`) нужен драйвер WinUSB.
Вкладка RCM автоматически показывает статус драйвера и шаги установки через [Zadig](https://zadig.akeo.ie/).

## Payload (фаза 2)

На вкладке RCM можно отправить payload (hekate, TegraExplorer и т.п.) через fusée gelée:
код исполняется только в RAM, eMMC не затрагивается, перед отправкой — подтверждение.
Требуется незалоченная erista (patched/mariko не примут эксплойт).
Файл payload выбирается вручную и в репозитории не хранится.

## Принцип «read-only»

- На консоль ничего не пишется: ни eMMC, ни фьюзы, ни калибровка.
- Payload фазы 2 (hekate) выполняется только в RAM и не модифицирует накопитель.
- Все действия, выходящие за рамки чтения, сопровождаются явным предупреждением.
