# Дерево симптомов → вероятные причины (черновик, фаза 1)

Формат записи для мастера поломок. Чипы — кандидаты, порядок = примерный приоритет проверки.

## Питание / включение

### Совсем не включается (нет реакции, индикатор заряда не горит)
- USB-C порт (механика/окисление)
- M92T36 (PD-контроллер) — частый виновник
- BQ24193 (зарядный IC)
- Батарея (глубокий разряд, BMS)
- PMIC (MAX77620) / цепи питания SoC

### Включается, но чёрный экран, подсветки нет
- Шлейф дисплея / разъём
- Панель (подсветка)
- Рейка/плата (после падения/жидкости)

### Подсветка есть, изображения нет
- Панель (матрица)
- Шлейф (частично)
- SoC/GPU (реже)

## Заряд

### Не заряжается, но работает
- USB-C порт
- M92T36
- BQ24193

### Заряжается только при определённом положении кабеля
- USB-C порт (механика) — почти наверняка

### Быстро разряжается / выключается на 30–60%
- Батарея (износ) — проверить фазой 2 (MAX17050: cycles, age, V@empty)
- Калибровка fuel gauge

## Загрузка

### Не грузится дальше логотипа / циклическая перезагрузка
- eMMC (умирает/отвалился) — фаза 2: eMMC health
- Прошивка (после неудачного обновления)
- boot0/boot1

### RCM виден (APX), система не грузится
- eMMC отсутствует/мёртв
- Прошивка
- (SoC и питание в порядке — это уже половина диагноза)

## Периферия

### Не видит Joy-Con (одна сторона)
- Рейка/шлейф рейки
- Контроллер на рейке

### Нет Wi-Fi / Bluetooth
- Модуль Wi-Fi/BT (чип — уточнить, см. FACTS_TO_VERIFY #7)
- Антенный кабель

### Дрейф стиков
- Сам Joy-Con (потенциометры) — консоль тут не при чём

## Температура

### Перегрев / троттлинг / громкий вентилятор
- Термопаста/термопрокладки
- Вентилятор (пыль, подшипник)
- Радиатор (пыль)
